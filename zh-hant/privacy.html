SpeakZilla 隱私權政策

本文件為英文版隱私權政策的中文翻譯；如中文版與英文版內容有任何不一致，以[英文版](https://speakzilla.app/privacy)為準。

生效日期： 2026年8月19日

最後更新： 2026年9月23日

SpeakZilla（以下簡稱 SpeakZilla 或我們）是一款發音練習 App，由加拿大安大略省的 Andrew Kim 經營。本政策說明我們蒐集哪些個人資料、蒐集的原因、與誰分享，以及你擁有的選擇與權利。

如有任何問題，請透過 support@speakzilla.app 與我們聯絡。

---

1. 本政策的適用對象

本政策適用於所有在網頁上或在我們的行動 App 中建立帳號或使用 SpeakZilla 的人。

2. 我們蒐集的資訊

a) 帳號資訊

  • 你的電子郵件地址和密碼（密碼只會由我們的身分驗證服務供應商以雜湊形式儲存，我們絕不會看到或儲存你的原始密碼）。
  • 顯示名稱，預設由你的電子郵件地址產生。
  • 如果你使用 Apple 或 Google 登入，而不是使用密碼：該供應商提供給我們的電子郵件地址，以及在該供應商有分享的情況下，你的姓名和大頭貼照片，我們會將其顯示在你的個人檔案（我的）頁面上。除此之外，我們不會從你的 Apple 或 Google 帳號收到任何其他資訊，也絕不會看到該帳號的密碼。
  • 兩項設定，讓 App 能為你正確運作：你的時區（讓每日上限、連續打卡和每日任務在你自己的午夜更新），以及你選擇的 App 語言（讓帳號相關郵件以該語言寄給你）。

b) 學習活動與進度

  • 你的課程進度、分數、準確度紀錄、連續打卡、點數、代幣、每日任務，以及你已完成哪些課程。

c) 你的語音及其逐字稿 *（最重要的類別，請見第 3 節）*

  • 當你練習時，你的語音會被擷取並串流傳送以進行評分，同時會產生你所說內容的文字逐字稿。
  • 我們會儲存逐字稿和據此得出的發音分數（整體分數，以及每個單字／每個發音的分數）。在行動 App 上，我們不會儲存音訊本身，請見第 3 節。

d) 自動蒐集的資訊

  • 營運及保護服務所需的基本技術資料（例如 IP 位址、裝置／瀏覽器類型及時間戳記），由我們的主機代管及後端服務供應商透過標準伺服器紀錄檔蒐集。

我們不會蒐集付款資訊、精確位置、你的聯絡人，也不會從 Apple 或 Google 帳號蒐集 (a) 所列內容以外的任何資訊。

3. 語音資料：運作方式

由於 SpeakZilla 會為發音評分，使用它必然涉及錄下你的聲音。具體而言：

  • 擷取：你練習時，App 會在你大聲唸出句子的同時擷取你的語音。
  • 處理：你的語音會串流傳送至 Microsoft Azure AI Speech，由其即時轉錄語音、評估發音準確度，並回傳分數。關於 Microsoft 如何處理音訊，請參閱 Microsoft 的條款。
  • 儲存：行動 App 不會保留你的錄音。我們儲存的是據此產生的逐字稿和分數（整體、每個單字及每個發音），讓你可以回顧進度，也讓間隔重複等功能能再次帶出你覺得困難的發音。若有錄音被儲存（例如你在網頁上使用 SpeakZilla），該錄音會在 90 天後自動刪除。

你可以掌控這些資料，請見你的權利（第 7 節）。如果你不希望自己的聲音被錄下，就不應使用練習功能，因為這些功能沒有錄音就無法運作。

4. 我們如何使用你的資訊

我們使用上述資料來：

  • 提供核心服務：辨識你的語音並為發音評分；
  • 記錄並顯示你的進度、連續打卡和成就；
  • 將練習個人化（例如再次帶出你覺得困難的發音）；
  • 營運、保護、除錯及改善 App；
  • 就你的帳號與你聯繫（例如重設密碼）。

我們不會出售你的個人資料，也不會使用你的錄音來建立或訓練語音模型。

5. 我們與誰分享資料（服務供應商）

我們僅為營運 SpeakZilla 而與下列資料處理者分享資料。各處理者皆代表我們處理資料，並適用其各自的條款與安全控管措施：

供應商用途處理的資料
Supabase資料庫、身分驗證、檔案儲存帳號、進度和逐字稿。錄音僅來自網頁版 App；行動 App 不會上傳任何錄音
Microsoft Azure AI Speech語音辨識 + 發音評估；文字轉語音音訊片段和參考文字
Cloudflare網站代管與傳送技術／紀錄檔資料（例如 IP）
Resend寄送帳號相關郵件（確認你的電子郵件地址、重設密碼）你的電子郵件地址和郵件內容
Expo (EAS Update)傳送 App 更新技術資料（例如 IP、App 版本、裝置平台），以及用來計算更新下載次數的匿名單次安裝識別碼。不含帳號資料

請查閱各供應商自己的隱私權文件：

  • Supabase：https://supabase.com/privacy
  • Microsoft Azure：https://privacy.microsoft.com
  • Cloudflare：https://www.cloudflare.com/privacypolicy/
  • Resend：https://resend.com/legal/privacy-policy
  • Expo：https://expo.dev/privacy

如果你選擇使用 Apple 或 Google 登入，它們即為登入服務供應商。它們不是我們的資料處理者，你在它們那裡的帳號受其各自的隱私權政策規範。

我們也可能在法律要求時、為保護我們的權利時，或作為業務移轉（例如合併或收購）的一部分而揭露資料；在此情況下，我們會在法律要求時通知你。

6. 資料保存

只要你的帳號仍在使用中，我們就會保存你的帳號和進度資料。

行動 App 完全不會儲存你的錄音。你的語音會被串流傳送以進行評分，隨後即被捨棄；只有逐字稿和分數會被保留。若有錄音被儲存（目前僅限於你在網頁上練習的情況），該錄音會在 90 天後自動刪除。

當你刪除帳號時，我們會在 30 天內刪除你的個人資料或將其匿名化，但為遵守法律義務而必須保留的部分資料除外。

7. 你的權利與選擇

視你所在地區而定（例如依據 GDPR 或 CCPA/CPRA），你可能有權：

  • 存取我們持有的關於你的個人資料；
  • 更正不正確的資料；
  • 刪除你的資料（即被遺忘權）；
  • 匯出你的資料副本（資料可攜權）；
  • 反對或限制特定處理；
  • 在處理係基於你的同意時，撤回同意。

如要行使上述任何權利，請使用 App 內個人檔案（我的）頁面中的刪除帳號選項，或寄信至 support@speakzilla.app 與我們聯絡。我們會在適用法律規定的期限內回覆。你不會因為行使這些權利而受到差別待遇。

8. 資料安全

我們採用業界標準措施保護你的資料，包括傳輸加密、將每位使用者的資料限制為僅該使用者本人可存取的存取控管（資料列層級安全性），以及採用信譽良好的基礎設施供應商。沒有任何傳輸或儲存方式是 100% 安全的，因此我們無法保證絕對的安全。

9. 國際資料傳輸

SpeakZilla 在加拿大營運。你的帳號、進度和逐字稿由 Supabase 儲存在美國。你的語音由 Microsoft Azure AI Speech 在加拿大（Canada Central 加拿大中部區域）處理。Microsoft、Resend、Expo 和 Cloudflare 都是美國公司；Cloudflare 會從離你最近的資料中心提供網站。在必要時，我們會依賴適當的保護措施（例如標準契約條款及各供應商的資料處理協議）進行上述傳輸。

10. 兒童隱私

SpeakZilla 並非以未滿 16 歲的兒童為對象，我們也不會在知情的情況下蒐集他們的個人資料。如果你認為有兒童向我們提供了資料，請與我們聯絡，我們會將其刪除。

11. 本政策的變更

我們可能會不時更新本政策。如有重大變更，我們會通知你（例如透過電子郵件或 App 內通知），並更新上方的最後更新日期。
